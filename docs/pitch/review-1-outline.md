# First review: pitch skeleton (≈5 min demo-led; fill once the statement is out)

Rule: every claim is defensible in an interview, every number is cited (docs/research), and the
demo carries the story. The slides only frame it.

1. **Hook (20 s).** One operator, one moment: a novice at a remote site who got the same coaching
   tip for the third time this week. The cost in downtime, wear and risk. One cited number.
2. **Problem (40 s).** The skills gap in figures (India plus global, cited), and why fixed courses
   and simulators don't close it: they aren't about this site, this task, today, or offline.
3. **What Cat already has (20 s).** The AI Assistant, VisionLink Coaching, eLearning, Simulators.
   We sit behind them and complement them. This shows the judges we did our homework.
4. **Solution + north-star KPI (30 s).** The thesis line. Tip recurrence as the metric Cat can
   check in its own data.
5. **Live demo (2 min).** event → generated lesson (cited, operator's language) → pre-shift
   briefing → competency passport → supervisor view → airplane mode: still works.
6. **Architecture (30 s).** One diagram covering data sources, the AI pipeline and its guardrails
   (citations, fallbacks), offline sync, and how the mobile version reuses the shared contracts.
7. **Proof and metrics (20 s).** What we measured: generation latency, citation coverage,
   offline load, and the lesson quality rubric.
8. **Roadmap + ask (20 s).** Mobile app (TestFlight), VisionLink and AI Assistant integration
   points, dealer rollout. Close with the tip-recurrence KPI.

## Backup slides
Data sources and the mock feed, our AI evaluation method, the security model (RLS, no PII),

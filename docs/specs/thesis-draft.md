# Product thesis — DRAFT (not frozen; re-shaped when the problem statement arrives)

Source: docs/research/08-founder-review.md (validated against 05, 06, 07).

## One line
A learning layer behind VisionLink and the Cat AI Assistant that turns every coaching tip,
near-miss and site condition into a cited micro-lesson in the operator's language, works on a
phone without signal, and proves competence with evidence. **The training writes itself from
the operator's real work.**

## Positioning (complement Cat, never copy)
| Cat already has | We add |
|---|---|
| Cat AI Assistant (answers questions, in-cab + off-board, on-device) | Turns answers and events into **structured learning and proof of skill** |
| VisionLink Operator Coaching (tips + manager dashboard) | Closes the loop: tip → lesson → practice → **tip recurrence ↓** |
| Cat eLearning (40+ fixed courses) | Lessons generated from **this site, this sector, this task, today** |
| Simulators (fixed, capital-heavy) | Phone-first, offline, affordable for small contractors |

**North-star KPI:** tip recurrence rate (same coaching tip re-firing after the operator was coached).
Secondary: time-to-proficiency, near-miss rate, lesson completion offline.

## Core features (ranked: judge wow × 24 h web feasibility)
1. Event → lesson engine with cited sources (no uncited safety advice).
2. Pre-shift briefing tuned to sector, task, weather and terrain.
3. Competency passport + supervisor view.
4. SOP / manual → multilingual course generator.
5. Offline pack (installable web app, pre-recorded audio).

## If the statement narrows
- Safety only → near-miss → lesson; pre-shift briefing leads.
- Training only → features 1, 3, 4 lead.
- Assistant only → off-machine companion for fleets without Cat's new in-cab hardware.
